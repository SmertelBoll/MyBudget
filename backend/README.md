# MyBudget — backend

Node.js 20+, Express 5, MongoDB (Mongoose). API під префіксом `/api/v1`.

## Запуск

```bash
npm install
cp .env.example .env   # заповнити MONGODB_URI, JWT_ACCESS_SECRET, JWT_REFRESH_SECRET
npm run seed:i18n      # залити словники з i18n/*.json у базу (необов'язково: англійська вбудована)
npm run dev            # http://localhost:4444
```

Тести (піднімають тимчасовий MongoDB у пам'яті; перший запуск завантажує його бінарник):

```bash
npm test
```

## Деплой на Render

Web Service, root directory `backend`, build `npm install`, start `npm start`. Змінні середовища — з `.env.example`.
`/health` — легкий запит для «прогріву» безкоштовного інстансу при старті додатку.

## Структура

| Папка | Що там |
|---|---|
| `controllers/` | обробники маршрутів |
| `models/` | схеми Mongoose; `syncedSchema.js` — спільні поля синхронізованих колекцій |
| `validations/` | схеми zod для тіл запитів |
| `utils/syncEngine.js` | push/pull синхронізації, правила, які не можна довірити клієнту |
| `jobs/` | курси валют (щогодини перевіряє, оновлює раз на добу), очищення сесій і видалених записів |
| `i18n/` | словники; нова мова = новий файл + `npm run seed:i18n` |

## Як працює синхронізація

- Ідентифікатори створює клієнт (UUID), тому записи можна робити офлайн.
- `POST /sync/push` `{ epoch, changes: [{ collection, id, op: "upsert" | "delete", data }] }` — до 500 змін;
  кожна отримує свій результат (`applied` / `rejected` + код помилки). Повтор пакета нічого не дублює.
- `GET /sync/pull?since=<cursor>&epoch=<n>` — усі зміни після курсора, з `cursor` і `hasMore`.
- Видалення — «надгробки» (`deleted: true`), остаточно прибираються через 30 днів.
- `epoch` змінюється після «Видалити всі дані»: пристрій зі старим `epoch` отримує `reset: true`,
  стирає локальну копію й тягне все з нуля.
- Сервер одночасно обробляє лише одну синхронізацію на користувача (блокування в пам'яті), тому
  розрахований на один інстанс.

## Помилки

Сервер повертає `{ code }` (наприклад `auth.invalidCredentials`), без тексту для користувача. Текст бере клієнт
зі словника за цим ключем.
